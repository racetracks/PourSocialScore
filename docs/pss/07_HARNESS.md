# PSS harness (tools/harness)

The general harness is baseline 06. PSS's commands, as of 3.4.0.25 (D2: the old windows' checks are gone). Needs `lua5.1` (apt) and `git fetch --depth=2000 origin main` (compares, and `validate_all.sh`'s upgrade checks, which rebuild old versions from history: in a shallow clone its "split" checks fail on 2.0.1 and 2.0.40). Real saves live only on scratch (the project files; there is no `/mnt/project-files`): with a scratch checkout (`racetracks/Pour-Social-Score_Scratch`), run `sh tools/harness/build_saves.sh <scratch checkout> [out dir]`: it writes `<out dir>/<version>/PourSocialScore.lua` for every `SavedVariables/<version>/` (a 3.x set joined core, Options, Logging, EllesmereUI; out dir defaults to `/tmp/pss-baselines`).

Other checks worth knowing: `check_keep`, `check_ondemand`, `check_recent`, `check_savedlog`, `check_growth`, `check_ownguild`, `check_guildrule`, `check_communities_seen`; `bench_recent.lua` (the benchmark behind the 144-slot layout); `show_totals.lua`, `dump_counts.lua` for inspection.

Shipped lists (3.4.1.37, N3): after any rebuild with `tools/PSS_BuildManaged.lua` (`--reindex`; it drops or converts surname-as-realm names against its `REALMS` table), run `check_packed`, `check_communities` and `check_communities_seen`, and `tui_compare.sh` (only the member counts should change). `validate_all.sh`'s split check runs the old 3.0.0-dev12 build, which still ships the pre-N3 lists, so it expects `membersShown` 196 lower, plus one for each member the save stores under a dropped name (`surname_stored.lua`). A later rebuild that changes the lists again must update those expectations too.

Stub (`wow_stub.lua`) additions for the new window: font objects with `GetFont` / `SetFont` (recorded), `GetShadowOffset` / `GetShadowColor`, `CreateFont`, `GetPoint`, `IsPlaying`, `GameFontDisable`, `ChatFontNormal`, and the parts of `ScrollFrameTemplate`, `InsetFrameTemplate`, `PanelTopTabButtonTemplate`. Widgets expose their Dark parts as `widget.pssParts` and the window its looks' art as `PSS_Window.art`, so checks reach them through frames (no test-only globals). Unknown `Set*`, `Scroll*` and similar calls return a no-op, so check a template part's type before indexing it.

PSS habits: a check that needs Libraries calls `M.PSS_Need("Libraries")` first; read every diff line on a real save before claiming "intended only". `tui_tour.lua` finds the window in `PourSocialScore_GUI` or, on a ref before 3.4.0.25, `PourSocialScore_UI`, so compares reach back past D2.
