# Connecting scratch to a session

The scratch repo is **`racetracks/Pour-Social-Score_Scratch`** (private, branch `main`). The old `racetracks/scratch` is no longer used: never read from or add to it.

1. The Claude GitHub App must be installed on it so sessions can push: https://github.com/apps/claude/installations/select_target
2. Add it to the session next to the addon repo (`add_repo`); if it cannot be added, say so and ask.
3. Work on `main` (`git checkout main`), whatever branch the session names for it (rule 15).
4. The index is `readme.md` at the root; each top folder has a README; Claude's criteria are in `CLAUDE.md`.

Links work for the author while signed in to GitHub.
