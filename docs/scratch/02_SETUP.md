# Setting up scratch (once)

The scratch repo is **`racetracks/Pour-Social-Score_Scratch`** (private).

1. Install the Claude GitHub App on it so Claude sessions can push: https://github.com/apps/claude/installations/select_target
2. Attach `racetracks/Pour-Social-Score_Scratch` to every Claude project, next to the project/addon repo.
3. The index is `readme.md` at the repo root; each top folder has its own README. Claude's criteria are in `CLAUDE.md`.
4. In a Claude session, check access with `git ls-remote https://github.com/racetracks/Pour-Social-Score_Scratch` (or the attached checkout) before relying on it.

Links work for the author while signed in to GitHub, because the repo is private.
